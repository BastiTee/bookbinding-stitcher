# Bookbinding Stitcher

---
**<https://bastitee.github.io/bookbinding-stitcher/>**

Early alpha for a tool to create, learn about, share, construct non-adhesive book bindings such as long stitch, or japanese bindings.

Feel free to leave comments, ideas, feedback via the issue tracker.

Examples to import can be found in the [respective folder](examples/).
